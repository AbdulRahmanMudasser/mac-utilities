# Mac Utilities

Mac Utilities is a native macOS menu-bar app that brings everyday system tools together in one place.

It includes network-usage history and comparisons, on-demand connection diagnostics, Wi-Fi link readings, Keep Awake controls, optional notifications, and local English/Urdu speech transcription.

## Privacy

Usage history, preferences, and transcripts stay on the device. Connection diagnostics send their test probes only to the endpoints selected for each check. Microphone audio is processed locally and is not saved; completed transcripts remain in History until deleted. The app does not collect analytics telemetry.
